5-step ML pipeline

Raw smart meter data flows through 5 algorithms — each adds a layer of intelligence before the final dashboard output.

01

Data Loading

UCI dataset loaded — 80K rows, 8 columns. DateTime parsed, missing values filled with column mean.

02

SLR + MLR

Simple LR finds consumption trend. MLR (R²=0.9982) predicts expected power and generates Deviation column.

03

Decision Tree

Threshold-based rules label each row as Theft, Fault, Surge, or Normal. 100% classification accuracy.

04

SVM

RBF kernel SVM does binary theft vs. not-theft check. Catches borderline theft cases DT may miss.

05

Random Forest

25 balanced trees give final label + confidence score. Voltage alone drives 89.25% of decisions.
